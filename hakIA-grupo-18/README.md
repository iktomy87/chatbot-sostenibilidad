# HackIAthon Devlights 2026 - Grupo 18

Repositorio oficial del Grupo 18 para la HackIAthon Devlights 2026.

## Instrucciones Git

- Clona este repositorio con las credenciales HTTPS proporcionadas.
- Trabaja en la rama `main`.
- Commitea y pushea tu progreso regularmente.

## Credenciales Git (HTTPS CodeCommit)

Las credenciales se encuentran en el formulario de entrega. Por favor, no las compartas públicamente.

## Base de Datos PostgreSQL

La base de datos solo es accesible desde las oficinas de Devlights. Ver detalles en el formulario de entrega.
